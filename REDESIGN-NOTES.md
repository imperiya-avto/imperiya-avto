# IMPERIYA AVTO visual refresh

This first-pass redesign updates only the visual layer in `public/index.html`.
Existing IDs, inline event handlers, API endpoints, and server logic are preserved.

## Changes
- Dark graphite / black DROPEZONE-inspired visual system
- Blue primary accent replacing the old gold accent
- Compact centered 568px game layout
- Floating bottom navigation with horizontal scrolling for all existing sections
- Restyled garage, income panel, car cards, cases, rewards, modals, and profile
- Mobile safe-area spacing and reduced-motion support

## Deploy
Replace the existing project files with this archive, commit/push to GitHub, and let Render deploy.
No package or server changes are required for this visual-only pass.
